## 服务器上安装 code-server，浏览器远程写代码

> 说明：本文用的是 code-server（服务端运行、浏览器访问），不是 VS Code 的 Remote SSH 插件方案。

## 安装
```bash
curl -fOL https://github.com/coder/code-server/releases/download/v4.2.0/code-server_4.2.0_amd64.deb
```
## 修改配置
```bash
vim ~/.config/code-server/config.yaml
# bind-addr: 后面的部分改成 0.0.0.0:xxxx（xxxx 表示端口号，可随意设置）
# password: 后面的部分改成你想要的密码
```
## 启动
code-server
