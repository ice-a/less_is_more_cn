## 创建 index 及 type

> 版本说明：Elasticsearch 7.x 起已移除 mapping type，下面 `test_type3` 以及 URL 中的类型段只适用于 6.x 及更早版本；7.x+ 请直接用 `PUT /索引名` + `mappings.properties`。

### put（暂时有问题）
```json
PUT /car_test_info
{
  "mappings": {
    "test_type3" : {
      "properties" : {
        "id" : {"type" : "long"},
        "username" : {"type" : "text"},
        "password" : {"type" : "text"},
        "age" : {"type" : "integer"}
      }
    }
  }
}
```

### post（测试 OK）
```json
POST /car_test_info_post/car_detail
{
  "properties" : {
    "id" : {"type" : "long"},
    "username" : {"type" : "text"},
    "password" : {"type" : "text"},
    "age" : {"type" : "integer"}
  }
}
```

## 查询 type 类型
GET /car_test_info_post/_mapping

## 在 type 中添加数据

### put(OK)
```json
PUT /car_test_info_post/car_detail/1
{
  "id": 22,
  "username": "zhangsan",
  "password": "666",
  "age": 1
}
```

### post
