## 修改配置文件关闭 Wayland

```bash
sudo vim /etc/gdm3/custom.conf
```

找到 `#WaylandEnable=false`，去掉行首的 `#` 让它生效：

```text
WaylandEnable=false
```

保存后重启显示管理器即可：

```bash
sudo systemctl restart gdm3
```
