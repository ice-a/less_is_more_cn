## 二、sign 参数还原实战（timestamp + nonce + key）

### 场景

```text
GET https://api.example.com/data?page=1
Params:
- timestamp: 1698765432100
- nonce: abc123
- sign: 8a9s8df8a9s8dfa9s8dfa9s8dfa9s8d
```

`sign` 每次请求都不同，缺失会被拒绝。

### 步骤

1. **抓包定位**：Chrome DevTools → Network → XHR，确认 `sign` 为必填且动态。
2. **全局搜索**：Sources 面板搜索 `sign`、`timestamp`、`nonce`、`encrypt`、`generateSign`、`md5`、`sha1`、`hmac`。
3. **分析算法**：常见形态是 `md5(timestamp + nonce + key)`，key 可能固定，也可能从其它接口动态取。
4. **Python 复现**：按同一拼接顺序计算，与抓包值比对。

### 变体

- HMAC-SHA256：`hmac.new(key, msg, hashlib.sha256).hexdigest()`
- RSA / AES：`pycryptodome`、`rsa`，或先用 Frida 拿到明文/密钥再移植
- 参数排序后拼接、body 参与签名：把排序逻辑一并搬进 Python

## 三、Python 签名模板

```python
import hashlib
import hmac
import os
import time

# 密钥从环境变量读取，不要写死在仓库里
SIGN_KEY = os.environ.get("SIGN_KEY", "")


def md5_sign(timestamp: int, nonce: str, key: str = SIGN_KEY) -> str:
    raw = f"{timestamp}{nonce}{key}"
    return hashlib.md5(raw.encode("utf-8")).hexdigest()


def hmac_sha256_sign(message: str, secret_key: str = SIGN_KEY) -> str:
    return hmac.new(
        secret_key.encode("utf-8"),
        message.encode("utf-8"),
        hashlib.sha256,
    ).hexdigest()


if __name__ == "__main__":
    ts = int(time.time() * 1000)
    nonce = "randomNonce123"
    print("[MD5]       ", md5_sign(ts, nonce))
    print("[HMAC-SHA256]", hmac_sha256_sign(f"{ts}{nonce}"))
```

## 四、Frida 入门

Frida 是动态插桩工具，可 Hook 运行中进程的函数，打印/修改参数与返回值，不需要反编译。

### 安装

```bash
pip install frida-tools
```

Android 设备安装 frida-server（选对应架构，如 arm64）：

```bash
adb push frida-server /data/local/tmp/
adb shell chmod +x /data/local/tmp/frida-server
adb shell /data/local/tmp/frida-server &
```

### 基础用法

```bash
frida-ps -U                                  # 列出 USB 设备进程
frida -U -n com.example.app -l hook_sign.js # 附加并加载脚本
frida -U -f com.example.app -l hook.js --no-pause  # spawn 启动
```

不知道函数名时，用 `Java.enumerateMethods("com.example.app.*")` 枚举，或在 jadx 里搜 `sign(`、`encrypt(`、`getDeviceId(`。

## 五、Frida 高级脚本

| 目标 | Hook 点 | 能拿到什么 |
| --- | --- | --- |
| RSA | `javax.crypto.Cipher.doFinal` | 明文/密文、算法名 |
| AES | `Cipher.doFinal`、`SecretKeySpec`、`IvParameterSpec` | key、iv、明文/密文 |
| 自定义签名 | 目标类的 `generateSign` / `getSign` | 输入参数与签名值 |
| 设备指纹 | `getDeviceFingerprint` / `getDeviceId` | 指纹原文，可改返回值 |
| 反调试 | `checkFrida`、`isRooted` 等检测函数 | 原始判定，可强制返回 false |

```javascript
// hook_crypto.js —— RSA/AES 通用
Java.perform(function () {
    var Cipher = Java.use("javax.crypto.Cipher");

    Cipher.doFinal.overload('[B').implementation = function (input) {
        var result = this.doFinal(input);
        console.log("[*] Cipher.doFinal()");
        console.log("    in :", bytesToHex(input));
        console.log("    out:", bytesToHex(result));
        return result;
    };

    Cipher.getInstance.overload('java.lang.String').implementation = function (algo) {
        console.log("[*] Cipher.getInstance:", algo);
        return this.getInstance(algo);
    };
});

function bytesToHex(bytes) {
    var out = '';
    for (var i = 0; i < bytes.length; i++) {
        out += ('0' + (bytes[i] & 0xff).toString(16)).slice(-2);
    }
    return out;
}
```

```javascript
// hook_aes_key.js —— 拿 AES 的 key 与 iv
Java.perform(function () {
    var SecretKeySpec = Java.use("javax.crypto.spec.SecretKeySpec");
    SecretKeySpec.$init.overload('[B', 'java.lang.String').implementation = function (keyBytes, algo) {
        console.log("[*] AES Key:", bytesToHex(keyBytes), "algo:", algo);
        return this.$init(keyBytes, algo);
    };

    var IvParameterSpec = Java.use("javax.crypto.spec.IvParameterSpec");
    IvParameterSpec.$init.overload('[B').implementation = function (ivBytes) {
        console.log("[*] AES IV:", bytesToHex(ivBytes));
        return this.$init(ivBytes);
    };
});
```

```javascript
// hook_sign_function.js —— 自定义签名函数
Java.perform(function () {
    var SecurityUtils = Java.use("com.example.app.utils.SecurityUtils");
    SecurityUtils.generateSign.implementation = function (params) {
        console.log("[*] generateSign 入参:", params);
        var sign = this.generateSign(params);
        console.log("[+] generateSign 返回:", sign);
        return sign;
    };
});
```

// hook_fingerprint.js —— 设备指纹改返回值

## 六、通用技巧与资源

- 打印 byte[] 统一转 hex，避免 Frida 输出乱码。
- 需要稳定复现时优先 `Java.enumerateMethods` / `Java.choose` 动态定位，别写死偏移。
- iOS（Objective-C/Swift）与 Native（C/C++）层 Hook 语法不同，可参考 [Frida 官方文档](https://frida.re/docs/home/) 与 [JavaScript API](https://frida.re/docs/javascript-api/)。
- 中文进阶合集：[frida-all-in-one](https://github.com/hookmaster/frida-all-in-one)。

## 七、总结

工具清单解决「用什么」，第二章解决「怎么定位和复现 sign」，第四、五章解决「App 内加密/指纹/反调试怎么拿」。遇到具体目标时，先抓包定位 → Sources 搜关键字 → 必要时 Frida 打印 → Python 复现，这条链路通吃大多数签名类接口。
