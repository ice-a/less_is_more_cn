## 下载支持的 cuda 版本

## 下载对应 cuda 版本的 cudnn 版本

cuDNN 必须和 CUDA 主版本匹配，下载入口是 [NVIDIA cuDNN 归档](https://developer.nvidia.com/cudnn)（不是 CUDA Toolkit 页面）。新版本多为压缩包或 runfile：解压后把 `bin/`、`include/`、`lib/` 里的文件复制到 CUDA 安装目录的对应位置；用 runfile 安装时注意不要覆盖已有的 CUDA 运行时。旧版安装器可一路默认。![cudnn.png](https://i-blog.csdnimg.cn/img_convert/c74c1a7d85d940deead0992fa98fdef9.png)

## 下载对应 cuda 的 torch 版本

在 [PyTorch 官网下载页](https://pytorch.org/get-started/locally/)按「CUDA 版本 + pip」生成命令，注意它给出的 `--index-url` 会替换默认源。CUDA 11.8 对应：

```bash
pip3 install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu118
```

安装前确认 Python 版本在该 PyTorch 版本的支持范围内，避免装上不匹配的轮子。

![torch.png](https://i-blog.csdnimg.cn/img_convert/121fd91e024454a713d304cb2b212b7a.png)

## 测试炼丹的环境安装是否成功

```python
import torch

print(torch.__version__)
print("CUDA available:", torch.cuda.is_available())
print("CUDA version:", torch.version.cuda)
print("GPU:", torch.cuda.get_device_name(0))
```

`torch.cuda.is_available()` 为 `False` 时先查驱动版本是否满足所装 CUDA，再看是不是装成了 CPU 版轮子。
