和 AI、模型相关的实践记录：语音合成、训练环境搭建、数据集处理，以及用大模型辅助学习和做数据解析。

本分类共 6 篇笔记。

- [TTS 语音合成](./20240101_01_tts语音合成.md) —— 开源 TTS 语音合成项目清单，涵盖 Coqui TTS、ChatTTS、GPT-SoVITS 等及其 GUI 情况。
- [音频数据集](./20250101_02_音频数据集.md) —— 语音与音频数据集的收集记录，整理了公开数据集的获取方式。
- [炼丹环境 PyTorch](./20250101_03_炼丹环境pytorch.md) —— PyTorch 训练环境搭建记录：确认显卡支持的 CUDA 版本、下载对应 cuDNN 与安装流程。
- [利用龙猫 AI 实现解析数据](./20260302_01_利用龙猫ai实现解析数据.md) —— 传统的爬虫解析依赖于 XPath、CSS Selector 或正则表达式。这些方法对网页结构的微小变动非常敏感（例如：div 层级变化或 class 名混淆）。
- [逆向激进 Prompt](./20260302_02_逆向激进prompt.md) —— 用于逆向与反爬研究的一段「激进」系统提示词样例，可作为 prompt 写作参考。
- [利用 AI 辅助零基础学习路径](./20260302_03_利用ai辅助零基础学习路径.md) —— 这份计划专为零基础（无 JS 逆向经验、无移动端开发经验）量身定制。核心理念是：用 AI 弥补代码能力的不足，用工具替代繁琐的人工分析。
