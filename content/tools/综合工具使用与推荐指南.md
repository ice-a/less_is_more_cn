## 🚀 快速安装指南

### 1️⃣ Netcatty（SSH 工作空间）

Netcatty 是一款现代化 SSH 客户端与终端管理器，专为需要高效管理多台远程服务器的开发者、系统管理员和 DevOps 工程师设计。它集成了 SSH 终端、SFTP 浏览器和 AI 助手（Catty Agent），支持分屏终端与 Vault 主机管理。

**安装方法**：

```bash
# Windows（Scoop）
scoop install lemon/netcatty

# Windows（Winget）
winget install binaricat.Netcatty

# macOS（DMG）
# 下载 DMG 后拖入 Applications
xattr -cr /Applications/Netcatty.app

# Linux（DEB）
sudo dpkg -i netcatty_*.deb
```

**核心功能**：
- **分屏终端**：多窗格、多标签页、会话恢复
- **双窗格 SFTP**：本地与远程文件拖拽传输，支持远程服务器之间直接传输
- **Vault 主机管理**：网格/列表/树形视图，快速搜索
- **Catty Agent**：AI 辅助服务器诊断、日志分析与命令生成
- **云同步**：支持 GitHub Gist、Google Drive、S3、WebDAV，端到端加密

**首次配置**：
1. 打开 Netcatty，在 Vault 中点击 **＋** 添加主机
2. 填写 `user@server-ip`，选择认证方式（密码 / 私钥）
3. 连接成功后，右键标签 → **分屏** 启用多窗格
4. 点击左下角 **SFTP** 图标，开启双窗格文件浏览

### 2️⃣ Magpie（窗口放大器）

Magpie 是一款轻量级 Windows 窗口放大工具，可将任意窗口放大至原生分辨率，特别适用于低分辨率游戏或老软件。

**安装方法**：

```bash
# 方式一：Winget
winget install Blinue.Magpie

# 方式二：GitHub Releases
# 从 https://github.com/Blinue/Magpie/releases 下载最新版
```

**核心算法**：

| 游戏类型 | 推荐算法 | 缩放倍数 | 特殊设置 |
|----------|----------|----------|----------|
| 像素游戏 | xBRZ_4x | 2x-3x | 开启 CRT 扫描线 |
| 3D 老游戏 | FSR_EASU | 1.5x-2x | 启用 3D 游戏模式 |
| 动漫风格 | Anime4K | 2x | 降噪强度 0.3 |
| 复古街机 | CRT_Geom | 1x-2x | 扫描线强度 0.4 |

**快捷键**：
- `Alt+Shift+A`：切换全屏/窗口缩放
- `Alt+Shift+Q`：退出缩放
- `Alt+F11`：快速放大当前窗口

**首次配置**：
1. 运行 `magpie.exe`
2. 在 **缩放模式** 下拉框选择算法
3. **捕获方式** 选择 `GDI` 或 `WinRT Capture`
4. 点击 **注入模式**，选择 `Runtime Injection`
5. 选中目标窗口，按快捷键生效

### 3️⃣ Unsloth（LLM 微调）

Unsloth 是一款开源的 LLM 运行与训练框架，可让模型训练速度提升 2 倍，同时减少 70% 的 VRAM 占用，且不损失精度。

**安装方法**：

```bash
# Linux / WSL / macOS
curl -fsSL https://unsloth.ai/install.sh | sh

# Windows (PowerShell)
irm https://unsloth.ai/install.ps1 | iex

# Homebrew (macOS)
brew install --cask unsloth

# Winget (Windows)
winget install --id UnslothAI.Unsloth -e

# Docker
docker pull unsloth/unsloth
```

**核心功能**：
- **本地运行 GGUF / MLX / 扩散模型**（文本、图像、视频、TTS）
- **训练 500+ 模型**，支持 QLoRA / LoRA
- **Unsloth Studio**：无代码 Web UI，支持自动数据集创建与可视化训练
- **精准工具调用**：自愈式工具调用与沙箱代码执行
- **本地 Agent**：将本地 LLM 接入 Claude Code / Codex 等代理工具

**QLoRA 微调示例**：

```python
from unsloth import FastLanguageModel
import torch

# 加载模型（4-bit 量化）
model, tokenizer = FastLanguageModel.from_pretrained(
    model_name="unsloth/Qwen2.5-7B-Instruct",
    max_seq_length=2048,
    dtype=None,
    load_in_4bit=True,
)

# 添加 LoRA 适配器
model = FastLanguageModel.get_peft_model(
    model,
    r=16,
    target_modules=["q_proj", "k_proj", "v_proj", "o_proj"],
    lora_alpha=16,
    lora_dropout=0,
    bias="none",
    use_gradient_checkpointing="unsloth",
    random_state=3407,
)

# 训练
from trl import SFTTrainer
trainer = SFTTrainer(
    model=model,
    tokenizer=tokenizer,
    train_dataset=dataset,
    max_seq_length=2048,
)
trainer.train()
```

### 4️⃣ Orca（计算机使用）

Orca 是一款 AI 驱动的桌面应用操控工具，可通过命令行读取窗口状态、点击元素、执行自动化操作。

**安装与权限**：

```bash
# 检查运行状态
orca status --json

# 检查权限
orca computer permissions --json
```

**权限配置**：
1. 打开 **系统设置 → 隐私与安全 → 辅助功能**
2. 将 **Orca Computer Use** 开关设为 **开启**
3. 同时开启 **屏幕录制** 权限
4. 若更新后权限失效，需手动关闭→重新开启开关

**核心命令**：

```bash
# 列出所有可见应用窗口
orca computer list-apps --json

# 获取指定应用状态
orca computer get-app-state --app com.spotify.client --json

# 点击元素
orca computer click --app com.spotify.client --element-index 42 --json

# 截图
orca computer screenshot --output screen.png
```

### 5️⃣ Pebrel（AI 终端）

Pebrel（前身为 Nebula）是一款 AI 原生、GPU 加速的终端模拟器，集成了本地 Shell、远程主机、SSH 与 SFTP，并深度支持 Claude Code 与 Codex 等 AI CLI 工作流。

**安装方法**：

```bash
# Windows（官网安装包）
# 下载 Pebrel-v*-setup.exe 并运行

# Homebrew (macOS)
brew tap yetone/magpie-releases https://github.com/yetone/magpie-releases
brew install --cask pebrel
```

**核心功能**：
- **GPU 加速渲染**：基于 Rust + GPUI，流畅渲染大量输出
- **分屏终端**：多窗格、多标签、持久化会话
- **SSH & SFTP**：内置远程主机管理
- **AI CLI 集成**：自动识别 Claude Code / Codex / Gemini CLI，可视化状态（Working / Blocked / Idle）
- **文档阅读器**：内置 Markdown / PDF 预览

**首次配置**：
1. 启动 Pebrel，进入 **设置 → AI 会话**
2. 配置 Claude Code 路径（`claude` 命令）
3. 配置 Codex 路径（`codex` 命令）
4. 在 **状态检测** 中启用 **Hook 事件** 以获取准确状态

### 6️⃣ DeepSeek Harness（AI Agent 框架）

DeepSeek Harness（`dsh`）是由 DeepSeek AI 开发的开源 Agent 框架，采用 **一切皆插件** 架构，由 Cordis 驱动。

**安装方法**：

```bash
# 方式一：npx 快速启动（推荐）
npx @deepseek-ai/dsh web

# 方式二：全局安装
npm install -g @deepseek-ai/dsh
dsh web

# 方式三：源码构建
git clone https://github.com/deepseek-ai/deepseek-harness.git
cd deepseek-harness
pnpm install
pnpm run build
pnpm dsh web
```

**启动后访问**：`http://127.0.0.1:3080`

**首次配置**：
1. 打开 Web UI，点击 **设置 → API Keys**
2. 填入 DeepSeek API Key（`sk-` 开头）
3. 选择默认模型（`deepseek-chat` / `deepseek-reasoner`）
4. 设置工作区路径（建议空文件夹）
5. 发送测试任务验证连接

**插件系统**：
- 在 **插件市场** 中搜索并安装所需插件（如文件读写、Web 搜索、终端执行）
- 每个插件需单独授权权限
- 插件配置文件位于 `~/.dsh/plugins/`

## 🆘 常见问题速查

| 问题 | 工具 | 解决方案 |
|------|------|----------|
| 快捷键无响应 | Magpie | 管理员运行 / 更换键位 |
| 放大后卡顿 | Magpie | 降低倍数 / 换轻量算法 |
| GPU 不可见 | Unsloth + Colab | 稍后重试 / 更换账号 |
| AI 权限丢失 | Orca | 系统设置中重新授权 |
| Screen Recording 未授权 | Orca | 系统设置 → 隐私 → 屏幕录制 → 开启 |
| 会话无法恢复 | Pebrel | 检查 AI CLI 钩子配置 |
| API 连接失败 | DeepSeek Harness | 检查 Key 格式 / 网络 |
