## 关于这个站点

这里是「爱喝水的木子」的个人笔记站，主要用来存放平时学习和工作里记录下来的东西。

写的东西比较杂，大致分成几类：

- **生活随笔**：偶尔写写生活、旅行和读书；
- **资源与链接**：学习资源、镜像站、UI 库、福利站点等入口收藏；
- **系统与运维**：Linux、环境变量、代理、远程连接、系统重装等基础配置；
- **容器与中间件**：Docker 部署 Elasticsearch、Hadoop 及常用服务；
- **网络服务与接口**：Flask 接口、限流、MySQL 主从、Redis 布隆过滤器、项目部署；
- **脚本集合**：Python / JS 小脚本、格式转换、数据提取、加解密等；
- **AI 与模型**：PyTorch 环境、语音合成、数据集、YOLO 训练与提示词；
- **爬虫与逆向**：反爬与风控、补环境、AST 解混淆、原型链、iOS 逆向、Frida；
- **工具与效率**：开发工具清单、SSH/抓包/数据库工具、OpenClaw 与 AI 终端。

内容以「自己能用」为准：写得对的会一直留着，写错或者过时的会改掉或者删掉。因为是个人笔记，所以不追求面面俱到，也不敢保证每篇都是对的，看的时候留个心眼。

## 正在学的方向

- 爬虫：异步爬虫、分布式调度、验证码识别、数据清洗；
- 逆向：JavaScript 逆向、Web API 逆向、App 逆向、协议分析；
- 反爬对抗：浏览器指纹、请求特征、行为模拟、代理池管理；
- 后端：Flask / FastAPI 风格的 API 服务、Docker 部署、数据库与缓存；
- 前端：Vue 生态、页面性能优化；
- 数据与算法：PyTorch 训练环境、模型推理、数据可视化。

上面这些大多只是学过、用过，还没有到能称为「精通」的程度。

## 站点的技术实现

本站使用 VitePress 搭建，部署在 GitHub Pages，源码放在 [GitHub](https://github.com/ice-a)。

- VitePress + Vue 3
- 侧边栏按「生活随笔 / 资源与链接 / 系统与运维 / 容器与中间件 / 网络服务与接口 / 脚本集合 / AI 与模型 / 爬虫与逆向 / 工具与效率」九个分组组织
- 全文搜索由 pagefind 提供
- RSS 订阅由 vitepress-plugin-rss 生成
